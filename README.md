========================================================================
                 INTEGRATIVE TASK PROJECT (JAVA)
========================================================================

1. PROGRAM ENTRY POINT (MAIN CLASS)
   The application starts from the Main class located at:
   -> src/ec/edu/uce/algorithms/Main.java
   (If using the Spanish package: src/ec/edu/uce/algoritmos/Main.java)

2. RUNNING FROM AN IDE (NetBeans, IntelliJ IDEA, Eclipse, or VS Code)
   - Open the project root folder (TareaIntegradora).
   - Open the file: src/ec/edu/uce/algorithms/Main.java
   - Click "Run" (execute the main method).
   - In the interactive console menu, type 5 and press Enter to run all
     activities sequentially (or select 1 to 4 to test each activity
     individually).

3. RUNNING FROM TERMINAL / COMMAND PROMPT (from the project root folder)
   - Step 1 (Compile):
     javac -encoding UTF-8 -d out src/ec/edu/uce/algorithms/*.java

   - Step 2 (Start interactive menu):
     java -cp out ec.edu.uce.algorithms.Main

   - Shortcut (Run ALL activities directly without menu prompts):
     java -cp out ec.edu.uce.algorithms.Main --all
     (Spanish package flag: java -cp out ec.edu.uce.algoritmos.Main --todo)

REQUIREMENTS: JDK 17 or higher (no external libraries or dependencies).
